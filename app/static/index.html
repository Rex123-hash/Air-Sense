    Data source

    UCI Air Quality Data Set — De Vito, S., Massera, E., Piga, M., Martinotto, L., & Di Francia, G. (2008). On field calibration of an electronic nose for benzene estimation in an urban pollution monitoring scenario. Sensors and Actuators B: Chemical, 129(2), 750–757.

    A contiguous 2000-row hourly slice (11 Mar – 23 Jun 2004) is used. Pipeline: Data → Cleaning → Features → Model → Forecast → Action.
